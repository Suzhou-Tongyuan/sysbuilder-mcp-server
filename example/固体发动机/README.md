# 固体发动机案例说明

本目录提供一个使用 Sysbuilder MCP Server 构建的固体发动机案例，包含建模需求、几何参数、示例工程文件、生成的 Modelica 模型以及操作录屏，可用于了解基于 MCP 的建模流程与交付物形式。

## 文件说明

- `固体发动机建模需求.md`
  - 案例的需求输入文件。
  - 包含场景背景、功能要求、性能要求、关键指标以及系统组成，可作为通过 MCP Server 驱动 AI 进行 SysML 建模的原始需求描述。

- `固体发动机系统项目.sybprojz`
  - 基于上述需求与参数构建得到的 Sysbuilder 工程示例文件。
  - 可直接在 Sysbuilder 中打开，用于查看案例模型、结构组织和建模结果。

  - `固体发动机系统几何参数.md`
  - 由案例工程进一步生成的几何参数文件。
  - 汇总了固体发动机系统及壳体、喷管、固体燃料、伺服系统、药柱、点火装置、控制系统等组成部分的尺寸与参数信息，可用于几何模型建模输入。

- `SysbuilderRootModel/`
  - 由案例工程进一步生成的 Modelica 模型目录。
  - 目录中包含 `package.mo`、根模型包以及单位导入等内容，可用于查看或复用由 Sysbuilder 导出的 Modelica 结果。

- `SysbuilderMCP录制.mp4`
  - 案例操作录屏文件。
  - 用于演示借助 Sysbuilder MCP Server 进行案例建模或相关操作的过程，便于快速了解实际使用方式。

## 建议阅读顺序

1. 先阅读 `固体发动机建模需求.md`，了解建模目标与需求背景。
2. 然后打开 `固体发动机系统项目.sybprojz`，查看实际建模结果。
3. 如需查看生成的几何参数信息，可阅读 `固体发动机系统几何参数.md`。
4. 如需查看导出的仿真模型，可进一步阅读 `SysbuilderRootModel/`。
5. 如需了解操作过程，可观看 `SysbuilderMCP录制.mp4`。
